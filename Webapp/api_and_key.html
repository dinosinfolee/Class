HTTP 요청 방식
요청 방식은 서버에 무엇을 하려는지 알리는 표시입니다. 어떤 방식을 사용할지는 API를 만든 회사가 기능에 맞게 정합니다.
방식의미예시
GET데이터 조회날씨 정보, 게시물 목록 가져오기
POST데이터 전송, 작업 요청번역, AI 답변 생성, 글 작성
PUT데이터 전체 수정프로필 정보 전체 변경
PATCH데이터 일부 수정닉네임만 변경
DELETE데이터 삭제게시물 삭제
이 예시의 번역 API는 입력 텍스트를 서버로 보내야 하므로 POST를 사용합니다. 제미나이, 클로드, GPT 같은 AI 서비스의 API도 대부분 POST를 사용합니다.
