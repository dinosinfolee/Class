google.script.run이란?
구글 앱스 스크립트가 제공하는 기능으로, 화면(index.html)의 JavaScript가 서버(Code.gs)에 있는 함수를 이름만으로 호출할 수 있게 해 준다.
google.script.run .withSuccessHandler(showItems) // ② 결과를 받을 함수 .getItems(); // ① 호출할 서버 함수
구분서버에 요청하는 방법
일반 웹앱주소로 요청함 fetch('/api/items')
앱스 스크립트함수 이름으로 호출함 google.script.run.getItems()
서버의 처리 결과는 바로 오지 않고, 처리가 끝나면 withSuccessHandler에 지정한 함수로 전달된다. 위 예시에서는 목록을 받으면 showItems 함수가 화면에 표시한다.
doGet()이란?
웹앱 주소로 접속하면 구글 앱스 스크립트가 실행하는, 이름이 정해진 함수다. Code.gs에 반드시 이 이름으로 작성해야 하며, 없거나 이름이 다르면 "스크립트 함수를 찾을 수 없음: doGet" 오류가 표시된다.
// 직접 작성: 웹앱 주소로 접속하면 이 함수가 실행됨 function doGet() { // index.html 파일로 화면을 만들어 전달 return HtmlService.createHtmlOutputFromFile('index'); }
함수이름실행 시점
doGet()정해진 이름
(직접 작성)		웹앱 주소로 접속할 때 앱스 스크립트가 실행
getItems()
saveItems()		임의의 이름
(직접 작성)		화면에서 google.script.run으로 호출할 때 실행
※ 예시 이름으로, 코드마다 다를 수 있음
이름의 Get은 "가져오다"라는 뜻의 HTTP 요청 방식 GET에서 왔다. 브라우저가 주소로 접속하는 것은 "화면을 가져오겠다"는 GET 요청이고, doGet은 이 요청을 받아 화면을 내주는 함수다. 시트의 데이터를 가져오는 일은 getItems가 맡는다.
