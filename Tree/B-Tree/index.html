TIP · B-트리 시뮬레이션 규칙 (펼치기 / 접기)

키는 중복 저장하지 않으며, 없는 키의 삭제는 트리를 바꾸지 않는다. 여러 키는 입력 순서대로 하나씩 삽입·삭제하고 매번 복구를 마친 뒤 다음 키를 처리한다. 최종 트리는 삽입·삭제와 균형 복구가 모두 완료된 상태이다.

  1. 차수 M차수 M은 최대 자식 수이며 최대 키 수는 M−1이다. 루트 이외 노드는 최소 ⌈M/2⌉−1개의 키를 갖는다. 내부 노드의 자식 수는 키 수+1이고 모든 단말은 같은 레벨이다. 최소 차수 t라는 다른 정의와 혼동하지 않는다.
  2. 루트 예외비어 있지 않은 루트는 키가 최소 1개이다. 내부 루트는 자식이 최소 2개이고, 단말 루트에는 최소 자식 수를 적용하지 않는다. 마지막 키를 지우면 빈 트리가 된다. 키 없는 내부 루트가 자식 하나만 가지면 그 자식을 새 루트로 올린다.
  3. 삽입은 재분배 우선단말에 먼저 삽입하고 키가 M개가 되어 넘치면, 같은 부모의 바로 옆 형제에 여유가 있는지 확인한다. 여유가 있으면 부모의 경계 키를 거쳐 재분배하고, 없으면 분할한다. 가득 찼다는 이유만으로 삽입 전에 미리 분할하지 않는다.
  4. 양쪽 형제 선택삽입 시 양옆 형제 모두에 여유가 있으면 왼쪽으로 넘긴다. 삭제 시 양옆 형제 모두 빌려줄 수 있으면 왼쪽에서 빌린다. 왼쪽이 불가능하면 오른쪽을 확인한다. 대상은 같은 부모의 바로 인접한 형제이며 멀리 있는 형제까지 연쇄 이동하지 않는다.
  5. 분할 시 부모로 올릴 키분할 시 정렬된 M개 키 중 ⌊M/2⌋+1번째 키를 부모로 올린다(1부터 센 위치). M이 홀수이면 가운데 키, 짝수이면 두 중앙값 중 큰 값이다. M=4에서 [10,20,30,40]은 30 승격, 왼쪽 [10,20], 오른쪽 [40]이다. 키가 5개이면 3번째, 6개이면 4번째 키를 올린다. 이 식은 키의 값이 아니라 정렬된 순서에서의 위치를 뜻한다. 승격한 키는 자식에 남기지 않는다.
  6. 내부 키 삭제오른쪽 인접 서브트리의 최솟값인 중위 후속자(직후 원소)로 대체하고, 그 키가 있던 단말에서 실제로 삭제한다. 전임자는 사용하지 않는다. 내려가기 전에 미리 병합하지 않고 실제 삭제 후 부족한 노드부터 보정한다.
  7. 삭제 · 빌림 우선, 병합은 왼쪽 우선최소 키 수보다 적어졌을 때만 보정한다. 형제가 최소 개수보다 많이 가지고 있어야 빌릴 수 있다. 빌림은 부모 경계 키를 내려받고 형제의 끝 키를 부모로 올리는 방식이다. 둘 다 빌려줄 수 없으면 부모 경계 키와 함께 병합한다. 왼쪽 형제가 있으면 왼쪽과, 없으면 오른쪽과 병합한다. 부모도 부족하면 위로 반복한다.
  8. 내부 노드 재분배 · 자식도 이동키만 옮기지 않고 해당 경계의 자식 포인터도 함께 이동한다. 분할은 부모로 전파될 수 있고, 루트 분할 시에만 전체 높이가 1 증가한다. 루트 축소 시에는 1 감소한다. HTML 높이는 빈 트리 0, 단말 루트 1의 레벨 수이며 재분배 횟수에는 삽입·삭제 재분배가 모두 포함된다.
